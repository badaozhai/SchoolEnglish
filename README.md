# 英语随声听（Android 原生首版）

项目范围：仅开发 Android 原生 App，当前不开发 iOS 版本。

当前版本只处理本地文件，不需要登录或联网：

- 从 QQ 下载后，通过系统文件选择器导入 `.rar`、`.mp3`、`.mp4`
- 也支持在 QQ 中使用“打开方式/分享”直接交给本 App 导入
- RAR 在 App 私有目录中解压，仅导入其中的 MP3/MP4
- Media3 播放音频和视频，支持暂停、倍速、单曲循环、顺序循环，并记忆每个文件的播放位置
- 所有文件保存在 App 私有目录，卸载 App 时系统会一并清理

首版不包含登录、注册、账号、课程商城、云同步等功能。当前播放在 App 内完成，后台/锁屏播放会在播放器稳定后再接入。

## 构建

使用 Android Studio Ladybug 或更新版本打开项目，安装 JDK 17 和 Android SDK 35，然后执行 Gradle Sync 和 `assembleDebug`。

当前开发环境没有安装 Java、Gradle 或 Android SDK，因此尚未执行实际编译。首次构建需要联网下载 Gradle 和 Maven 依赖。

## 导入说明

Android 不应依赖某个 QQ 私有目录路径。用户从 QQ 下载文件后，在 App 中点击右上角导入，使用系统文件选择器选择 QQ 下载的文件即可。

RAR 解压依赖 Junrar。当前代码按文件名导入压缩包中的 MP3/MP4，并对压缩包内路径做了扁平化处理；正式发布前应针对目标 RAR 版本和 Junrar 的商业许可做真机验证。
