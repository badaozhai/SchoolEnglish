# 英语随声听（Android 原生首版）

一款面向小学生英语听力练习的 Android 原生 App。首版只聚焦“导入文件并播放”，打开即可使用，不设置登录、注册或账号体系。

## 项目范围

- **平台**：仅 Android；当前不开发 iOS 版本。
- **技术路线**：Kotlin + Android 原生，不使用 Flutter。
- **数据方式**：本地文件、本地 SQLite；当前不依赖服务器或网络服务。
- **界面方向**：简约、小清新、轻玻璃质感，优先保证听力播放和录音稿阅读的可用性。

## 当前已实现

### 文件导入

- 从 QQ 下载文件后，在 App 内通过系统文件选择器导入。
- 支持在 QQ 中使用“打开方式/分享”将文件交给 App 导入（取决于系统和 QQ 展示的应用列表）。
- 支持导入 `.rar`、`.mp3`、`.mp4`。
- 一次可以选择多个文件。
- App 已内置配套的 40 个 MP3（约 74 MB），首次启动时自动复制到本地媒体目录，安装后无需再次导入这批音频。
- RAR 压缩包在 App 私有目录中解压。
- 支持压缩包内多层文件夹，保留相对目录结构，并递归扫描其中的 MP3/MP4。
- 自动处理同名文件，避免覆盖已有内容。
- 跳过 PDF 等非媒体文件，并拒绝包含 `..` 的危险路径，降低路径穿越风险。
- 列表支持删除已导入的媒体文件。

### 播放器

- 使用 Media3 ExoPlayer 播放 MP3 音频和 MP4 视频。
- MP3 支持播放、暂停和进度拖动。
- 支持 `0.75x`、`1x`、`1.25x`、`1.5x`、`2x` 倍速切换。
- 支持三种循环模式：不循环、单曲循环、顺序循环。
- 当前播放列表支持自动播放下一首，也可以使用列表中的其他文件切换播放。
- 记录每个媒体文件的播放位置，下次继续播放时恢复进度。
- MP4 在 App 内显示视频画面；MP3 显示音频播放控制。

### 录音稿与歌词式显示

- 内置录音稿 PDF：`app/src/main/assets/transcripts.pdf`。
- 内置音频资源：`app/src/main/assets/preset_media/`。
- 首次启动时解析 PDF，将录音稿按 Unit、Period、Assessment 分类写入 SQLite。
- 播放文件时，根据文件名匹配对应录音稿，例如 `Unit 1 Period 2` 或 `Assessment for Unit 1`。
- 播放 MP3 时显示录音稿句子列表，当前句高亮并自动滚动，视觉效果类似歌词。
- 数据库使用 `SQLiteOpenHelper`，包含录音稿正文、顺序和媒体匹配键。

### 本地存储与隐私

- 导入的媒体保存在 App 私有目录，其他应用不能直接读取该目录。
- 播放位置保存在 App 本地偏好设置中。
- 卸载 App 时，系统会一并清理这些私有数据。
- 当前没有登录、注册、云同步、课程商城或账号数据采集。

## 当前未实现 / 已知限制

- 尚未接入 AI 跟读录音和评分功能。
- 尚未接入 WhisperX、wav2vec2 或其他语音强制对齐服务。
- 当前录音稿同步是**按 MP3 总时长平均分配到句子**的句级近似同步，不是真实音频时间轴。
- 暂不支持逐词时间戳、逐词高亮、波形显示或录音回放。
- 当前播放器只在 App 页面内工作，尚未实现后台播放、锁屏控制和通知栏控制。
- RAR 解压依赖 Junrar；RAR5、特殊编码压缩包以及不同 Android 设备上的兼容性，需要在目标真机上继续验证。
- Junrar 的许可证和正式发布合规性，需要在发布前单独确认。
- 当前开发机没有可用的 Android SDK、JDK、Gradle 和模拟器，因此还没有在本机完成 APK 构建与模拟器启动测试。
- 内置音频会增加 APK 体积约 74 MB；后续发布版本可以改为按需下载，以减小安装包。

## 构建要求

建议使用 Android Studio Ladybug 或更新版本打开项目，并准备：

- JDK 17
- Android SDK 35
- 可联网的 Gradle/Maven 依赖下载环境

在 Android Studio 的 Gradle 面板运行 `app > Tasks > build > assembleDebug`。如果本机已经单独安装 Gradle，也可以在项目根目录运行：

```bash
gradle assembleDebug
```

生成的调试 APK 通常位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 使用流程

1. 打开 App，无需登录或注册。
2. 点击右上角“导入文件”。
3. 选择 QQ 下载的 RAR、MP3 或 MP4 文件；RAR 会自动递归解压并导入其中的媒体文件。
4. 点击列表中的音频开始播放；有匹配录音稿时，下方会显示句子并随播放高亮滚动。
5. 在播放面板中调整倍速和循环模式，需要时可以删除文件。

## 后续方向

后续若继续扩展，优先顺序建议为：真实音频时间轴对齐、后台/锁屏播放、跟读录音与评分。它们属于后续能力，不影响当前首版的本地导入和播放流程。
