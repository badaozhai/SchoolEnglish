# 英语随声听

“英语随声听”是一款面向小学英语听力练习的 Android 原生应用。它把本地音频、录音稿和播放器放在同一个练习界面中，不需要登录、注册或服务器账号。

## 当前能力

### 音频管理

- 首次启动自动安装内置的 40 个 MP3，打开即可播放。
- 从系统文件选择器导入 `.rar`、`.mp3` 和 `.mp4`，支持一次选择多个文件。
- 支持从 QQ 等应用使用“打开方式/分享”导入文件。
- RAR 会在应用私有目录中解压，递归扫描多层文件夹并保留相对目录结构。
- 自动处理同名文件，跳过 PDF 等非媒体文件，并拒绝包含 `..` 的危险路径。
- 支持删除已导入的媒体文件。

### 播放与界面

- 使用 Media3 ExoPlayer 播放 MP3 和 MP4。
- 支持播放、暂停、拖动进度、`0.75x`、`1x`、`1.25x`、`1.5x`、`2x` 倍速。
- 默认使用单曲循环，可切换为顺序循环或不循环。
- 同一时间只保留一个播放器实例；切换音频时会先停止并释放旧音轨。
- 记住每个媒体文件的播放位置，下次播放时恢复进度。
- 播放状态下，音频列表与播放区按约 `2:3` 垂直比例布局，列表不会覆盖播放控件。
- 通过音频焦点和耳机拔出处理，降低多音频和意外外放风险。

### 录音稿同步

- 内置 `app/src/main/assets/transcripts.pdf`，首次启动时解析到本地 SQLite。
- 根据文件名匹配 `Unit N Period M` 和 `Assessment for Unit N`。
- 长段落会拆分为句子，播放时高亮当前句并自动滚动。
- 句子时间轴使用词数加权，并为片头、片尾预留缓冲；它是句级近似同步，不是真实音频对齐。
- 同一音频重复点击或快速切换时，字幕状态与音频 ID 绑定，避免字幕区域偶尔变空。

### 悬浮字幕

- 在播放面板开启“悬浮字幕”后，最小化应用会显示大尺寸半透明字幕卡片。
- 悬浮卡片显示当前音频和当前句子，可拖动标题栏调整位置，点击关闭按钮即可收起。
- 需要在系统设置中允许本应用“显示在其他应用上层”；不同厂商可能还需要允许后台运行。
- 悬浮字幕使用前台服务，返回应用后会自动收起悬浮卡片。

## 数据与隐私

- 导入媒体、播放位置和录音稿数据库都保存在应用私有目录。
- 应用不上传音频、录音稿或播放记录，也没有登录、云同步和账号数据采集。
- 卸载应用时，系统会清理这些私有数据。

## 构建

环境要求：

- JDK 17
- Android SDK 35
- 可联网的 Gradle/Maven 依赖环境

项目已提交 Gradle Wrapper 8.7。macOS/Linux 使用：

```bash
./gradlew --no-daemon testDebugUnitTest assembleDebug
```

Windows 使用：

```bat
gradlew.bat testDebugUnitTest assembleDebug
```

生成的调试 APK 位于：

```text
app/build/outputs/apk/debug/app-debug.apk
```

小米等部分 MIUI 设备建议使用非流式安装：

```bash
adb -s <device-serial> install -r --no-streaming app/build/outputs/apk/debug/app-debug.apk
```

完整的开发、真机冒烟测试和发布检查见 [`docs/DEVELOPMENT.md`](docs/DEVELOPMENT.md)。

## 使用流程

1. 打开应用，不需要登录。
2. 点击右上角“导入文件”，选择 RAR、MP3 或 MP4；内置音频无需导入。
3. 点击媒体列表中的文件开始播放。
4. 有匹配录音稿时，在播放区查看当前句和自动滚动的句子列表。
5. 在播放区调整倍速、循环方式，或开启悬浮字幕。

## 已知限制

- 当前没有逐词时间戳、逐词高亮、波形、跟读录音或评分功能。
- 录音稿同步仍是句级近似时间轴，不能替代 WhisperX 等真实强制对齐方案。
- 尚未提供锁屏媒体控制按钮；悬浮字幕依赖系统悬浮窗权限和厂商后台策略。
- Junrar 对 RAR5、特殊编码压缩包的兼容性需要在目标设备继续验证，正式发布前需确认其许可证合规性。
- 内置音频会让调试 APK 约 92 MB；后续可改为按需下载以减小安装包。
